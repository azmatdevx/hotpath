# k6: correlation syntax

Extract in JavaScript from the response object and pass the value into the next request. Variables are plain JS and are per-VU when declared inside the default function.

```js
import http from 'k6/http';
import { check } from 'k6';
import { parseHTML } from 'k6/html';

export default function () {
  // JSON body
  const login = http.post(`${__ENV.BASE}/api/login`, JSON.stringify({ user: 'u', pass: 'p' }),
    { headers: { 'Content-Type': 'application/json' } });
  const token = login.json('data.token');
  check(token, { 'token extracted': (t) => !!t });

  // HTML hidden field
  const page = http.get(`${__ENV.BASE}/form`);
  const csrf = page.html().find('input[name=csrf]').attr('value');

  // Header or regex
  const loc = login.headers['Location'];
  const m = page.body.match(/nonce="([^"]+)"/);
  const nonce = m && m[1];

  http.post(`${__ENV.BASE}/submit`, { csrf, nonce },
    { headers: { Authorization: `Bearer ${token}` } });
}
```

## Tips
- `check()` records a failure but does not stop the iteration. Use `fail()` or an early `return` when a required value is missing.
- Cookies are kept per VU automatically by the default cookie jar. Use `http.cookieJar()` to inspect or set them explicitly.
- Prefer `res.json('path')` and `res.html().find(...)` over regex.
- Use `thresholds` to fail the run on high check-failure rates.
- Keep real tokens out of the script and out of committed HAR files; read secrets from `__ENV`.
