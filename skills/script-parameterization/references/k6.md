# k6: parameterization

Verify APIs against the k6 version in use.

## Loading data
```js
import { SharedArray } from 'k6/data';
import papaparse from 'https://jslib.k6.io/papaparse/5.1.1/index.js';
import exec from 'k6/execution';

const users = new SharedArray('users', () =>
  papaparse.parse(open('./users.csv'), { header: true }).data);

export default function () {
  const user = users[exec.scenario.iterationInTest % users.length];
  // or: users[exec.vu.idInTest - 1] for one row per VU
}
```

## Notes
- `SharedArray` holds data once in memory and shares it across VUs. Without it, each VU copies the data.
- Use `k6/execution` (`exec.vu.idInTest`, `exec.scenario.iterationInTest`) to index rows so VUs and iterations get distinct rows.
- Use `Math.random()` for random picks and `crypto.randomUUID()` or a combination of `exec.vu.idInTest` and an iteration counter for unique values.
- Use a `setup()` function to create data once, and `teardown()` to clean up. `setup()` returns data passed to every VU.
- Read secrets from `__ENV`, not from the script.
- In distributed or cloud runs, confirm how data files are distributed.
