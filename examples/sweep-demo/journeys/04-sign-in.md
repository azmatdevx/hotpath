# TC-04: Sign in

Epic: Journey sweep demo

## Preconditions
- The app is running at the base URL.
- A test user name is supplied in the TEST_USER environment variable.

## Steps
1. Open the account page.
2. Type the test user's name.
3. Click "Sign in".
4. Wait for the welcome message.

## Expected result
- The page shows "Welcome " followed by the test user's name.
